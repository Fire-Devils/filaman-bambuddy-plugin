Adds actual automatic cloud profile assignment to AMS slot Workflow since Bambuddy tracks Cloud profiles:

You can set a Bambu cloud profile on a Filament or Spool in Filaman, or a Spool in Bambuddy. But now when you scan the spool and place it in an AMS slot, the cloud profile will automatically be sent to the AMS for the slot just like Bambu tags work with official profiles.

Bambuddy cloud profile list (and therefore the profile selection box in Filaman) will show separate versions for different nozzle sizes-- it generally shouldn't matter if you pick the .4 or the .6, but let me know what you come across.
